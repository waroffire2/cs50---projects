# Harvard CS50 Projects

A collection of projects and problem sets completed for Harvard University's
CS50: Introduction to Computer Science.

The repository documents my progression through CS50, including programming
fundamentals, algorithms, memory management, data structures, and problem solving.

## Repository Structure

- **Scratch Princess and Knight Game** — Interactive game developed in Scratch
- **Week 1 Problem Set** — C fundamentals, conditionals, loops, and algorithms
- **Week 2 Problem Set** — Arrays, strings, cryptography, and command-line arguments
- **Week 3 Problem Set** — Algorithms, searching, sorting, and voting systems
- **Week 4 Problem Set** — Memory, pointers, file I/O, and image processing

## Technologies & Concepts

- C
- Scratch
- Algorithms
- Data Structures
- Pointers & Memory
- File I/O
- Cryptography
- Searching & Sorting
